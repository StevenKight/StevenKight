# Steven Kight

AI Engineer building production LLM and AI/ML systems, with research in GPU-accelerated programming and physics simulations.

## Focus Areas

- **Physics simulation & HPC** - GPU-accelerated N-body and collision simulation in C/C++, Fortran, and CUDA, building toward rigid body dynamics
- **ML systems** - production LLM and agent platforms, agent routing, and classification models
- **Applied mathematics** - deriving and implementing numerical models for computational physics

## Featured Projects

**[Physics Engine](https://github.com/StevenKight/Physics-Engine)** A multi-language HPC physics simulation engine with N-body gravity, octree + SAT collision detection, and a Blender addon, built in C/C++, Fortran, and CUDA with CMake for portable cross-platform builds. Rigid body dynamics are on the roadmap.

**[Wolfie: UWG Smart Assistant](https://github.com/StevenKight/UWG-Smart-Assistant)** A research project building a campus-specific AI assistant for University of West Georgia students. A Python recognition pipeline classifies student requests and routes them to task-specific handlers.

**[Home Media Stack](https://github.com/StevenKight/Home-Media-Stack)** A self-hosted home media server built on Docker with automated setup, privacy-first design, and no cloud required.
